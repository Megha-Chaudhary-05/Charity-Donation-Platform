# Charity Donation Platform

## Overview
A web-based platform that facilitates secure and transparent donations to charitable organizations. Donors can browse causes, make contributions, and track how their funds are used. Admins can manage users, campaigns, and fund allocation.

## Features
- User registration and login
- Browse and search donation causes
- Make online donations
- View donation history
- Track fund usage
- Admin panel for campaign and fund management

## Tech Stack
- **Frontend**: Streamlit
- **Backend**: Flask, Python
- **Database**: MySQL
- **APIs**: RESTful API with Flask
